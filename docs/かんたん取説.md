# AICR Factory かんたん取説

## 普段の使い方

1. Googleフォームへ画像CRの依頼を入力します。
2. 「ロゴ」から使用するロゴを選びます。不要な場合は「なし」を選びます。
3. フォームを送信したら、そのまま待ちます。回答行の追加直後にGitHub Actionsが起動します。
4. GitHub Actionsが新しい回答を確認し、依頼専用のJSONプロンプトを作成します。
5. Image2が画像を4枚生成し、選択したロゴを付けてChatworkへ送信します。

画像4枚の生成とChatwork送信にも数分かかるため、フォーム送信後は通常10〜15分程度を目安にしてください。GitHub側の混雑状況によっては、もう少しかかる場合があります。

通常はPCを起動しておく必要はありません。

## 出力される画像

- 広告部分は1080×1080の正方形です。
- ロゴは正方形広告の外側・上部左寄せに配置されます。
- ロゴの背景色は、見やすい黒または白を自動で選びます。
- フォームで「なし」を選ぶとロゴは付きません。
- 1依頼につき、フォーム指定の訴求軸とビジュアル要素を優先し、構図や見せ方が異なる4案を作ります。

## 自動実行

GitHub Actionsはフォーム送信時だけ起動します。処理がエラー終了した場合は、同じ回答行を1回だけ自動再実行します。それでも失敗した場合は停止し、手動確認が必要です。

```text
.github/workflows/process-new-requests.yml
```

GitHubのリポジトリで「Actions」→「Process new AICR requests」を開くと、実行状況を確認できます。

## 特定の行を作り直す

1. GitHubで「Actions」を開きます。
2. 「Process new AICR requests」を選びます。
3. 「Run workflow」を押します。
4. `row_number`へ作り直したいスプレッドシートの行番号を入力します。
5. 実行すると、同じ行を再生成してChatworkへ送信します。

同じ行を実行すると画像生成APIを再度使用し、Chatworkにも新しい投稿が追加されます。

## Chatwork

送信先は次のルームです。

https://www.chatwork.com/#!rid442334168

Chatworkには依頼内容、選択ロゴ名、生成画像4枚が投稿されます。

## うまく動かないとき

- GitHubの「Actions」で赤い失敗表示がないか確認します。
- フォームの回答行に必要な内容が入っているか確認します。
- GitHub Secretsの`OPENAI_API_KEY`、`CHATWORK_API_TOKEN`が登録されているか確認します。
- APIキーやトークンの値は、チャットやリポジトリへ直接貼らないでください。

分からない場合は、対象のスプレッドシート行番号とGitHub Actionsの実行URLを添えて確認します。
